# Чат симулация — подбор и обучение

Прототип на контролирана AI чат среда за тестване на кандидати по 10 сценария.

## Как да качиш на GitHub Pages
1. Създай нов public repo, напр. `chat-sim`.
2. Качи трите файла: `index.html`, `scenarios.js`, `README.md`.
3. Settings → Pages → Source: `Deploy from a branch` → Branch: `main` / root → Save.
4. След 1–2 минути линкът ще е: `https://<username>.github.io/chat-sim/`

## Режими
- **Кандидат** — вижда само чата; отговаря на клиента.
- **Ментор** — вижда очаквани действия, примерен отговор, последващи въпроси и полета за оценка (бързина, точност, емпатия).

## Бележки
- Всичко е front-end, без backend. Оценките се пазят само в паметта на страницата (при презареждане се губят). За трайно запазване добави `localStorage`.
- „AI“ отговорът е симулиран чрез ротация на последващите въпроси. За истински AI свържи с API (напр. OpenAI) и системен prompt по сценарий.
